AURA BEAUTY — Next.js Headless Shopify Storefront
Build Summary
==========================================

HOW TO RUN
----------
  npm install
  npm run dev       # http://localhost:3000
  npm run build     # production build
  npm run lint      # linting

ENVIRONMENT VARIABLES (create .env.local in project root)
-----------------------------------------------------------
  NEXT_PUBLIC_SHOPIFY_STORE_DOMAIN=your-store.myshopify.com
  NEXT_PUBLIC_SHOPIFY_STOREFRONT_TOKEN=your_storefront_access_token

  To get the Storefront Access Token:
  1. Open your Shopify Admin
  2. Go to Settings > Apps and sales channels > Develop apps
  3. Create a new app (or open existing)
  4. Under "API credentials" > Storefront API access scopes, enable:
       unauthenticated_read_product_listings
       unauthenticated_read_product_inventory
       unauthenticated_read_product_tags
       unauthenticated_read_collection_listings
       unauthenticated_write_checkouts
       unauthenticated_read_checkouts
  5. Copy the Storefront API access token

  The app gracefully degrades (empty grids, placeholder UI) when
  Shopify is not configured.

PAGES
-----
  /                           Homepage — hero banner, category grid, featured products, bestsellers
  /sale                       Sale items (products with compareAtPrice > price)
  /bestsellers                Best-selling products
  /brands                     All brands A-Z, linked to collection filters
  /collections/[handle]       Category pages with price/brand/volume/country filters
  /products/[handle]          Product detail page with gallery, price, add-to-cart
  /search?q=query             Search results page
  /cart                       Cart page (basic — enhance with CartItem/CartDrawer for full UX)
